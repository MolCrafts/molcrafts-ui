# React component catalog

Generated by `pnpm build:catalog`. Package names are unpublished internal names and will be aligned with molcrafts-ui later.
The only implementation is in packages/ui. Every listed component is consumed from the `@molcrafts/ui` root entry.

```tsx
import { Button } from "@molcrafts/ui";
import "@molcrafts/ui/styles.css";
<Button size="icon" aria-label="Add item">{/* official Fluent icon */}</Button>
```

Every public component has a Storybook entry, grouped as Foundations, UI, Blocks, Web Components, and Charts. A story does not mean state coverage is complete. Impeccable reviews one story file or iframe at a time. A full sidebar pass happens only when explicitly requested.
